# NASA habitat reference model

The two converted GLB files are the NASA/LaRC Advanced Concepts Lab Habitat
Demonstration Unit (Deep Space Habitat) model. NASA publishes the original
parts in `source/`; those use Draco compression. The `.glb.draco` source files
have been decoded into standard GLB geometry for Godot 4.7.

- NASA model page: https://science.nasa.gov/3d-resources/habitat-demonstration-unit/
- NASA source repository: https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Habitat%20Demonstration%20Unit
- NASA describes the model as a one-story, four-port habitat of approximately 56 cubic meters and states that its 3D resources are free to download and use.
- NASA image and media usage guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/

The model is used as a visual reference structure on the exterior landing pad.
The interior room plan and furnishings remain WAAVES project content. NASA's
model is a concept demonstrator, not a flight configuration.
